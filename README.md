# Tic-Tac-Toe ❌⭕

Классическая игра «Крестики-нолики» на Swift для iOS с поддержкой одиночного и мультиплеерного режимов.

---

### ✨ Фичи и возможности
- 🤖 **Игра против AI:** Одиночный режим с возможностью выбора уровня сложности компьютера.
- 🎮 **Локальный режим:** Полноценный игровой цикл для двух игроков на одном устройстве.
- 🧠 **Алгоритм:** Оптимальная проверка условий победы и ничьей после каждого хода.
- 🔄 **Перезапуск:** Мгновенный сброс игрового поля для начала новой сессии.

---

### 🔄 Текущий рефакторинг (В разработке)
Сейчас проект находится на стадии крупного обновления:
- 🏗️ **Архитектура:** Переход со стандартного MVC на более тестируемый паттерн `MVVM`.
- 🎨 **UI-слой:** Полный отказ от Storyboards в пользу гибкой верстки исключительно кодом (`Auto Layout` / `NSLayoutConstraint`).

---

### 🚀 Планы по развитию (Roadmap)
- [ ] **Локальный мультиплеер:** Реализация сетевой игры между устройствами через Wi-Fi и Bluetooth с использованием нативного фреймворка `MultipeerConnectivity`.

---

### 🛠️ Стек технологий

- **Архитектура:** `MVC` *(в процессе перехода на `MVVM`)*
- **UI:** `Swift` • `UIKit` • `Auto Layout` (iOS 15.0+)
- **Логика:** Кастомные структуры данных и алгоритмы AI для оценки ходов на поле 3х3.
